# Movie Recommender System

A hybrid movie recommendation system that combines **content-based filtering** and **collaborative filtering** to generate personalized movie recommendations.

The project explores multiple recommendation approaches, including TF-IDF-based content similarity, item-item collaborative filtering, matrix factorization, and a hybrid model. An interactive recommendation application was also developed using Gradio.

## Project Overview

The goal of this project is to build and evaluate different movie recommendation approaches and investigate whether combining content-based and collaborative filtering can improve recommendation performance.

The project includes:

- Exploratory Data Analysis
- Data preprocessing and feature engineering
- Popularity-based baselines
- Content-based recommendation
- Item-item collaborative filtering
- Matrix factorization using SVD
- Hybrid recommendation
- Personalized user recommendations
- Recommendation evaluation
- An interactive Gradio application

## Dataset

This project uses **The Movies Dataset** from Kaggle, which contains movie metadata and user-rating data for approximately 45,000 movies.

The dataset includes information such as:

* Movie metadata
* Genres
* Keywords
* Cast and crew
* Overview and tagline
* Release information
* Languages
* Production companies and countries
* User ratings

The dataset also includes a smaller ratings subset containing approximately **100,000 ratings from 700 users and 9,000 movies**, which is used in parts of the recommendation pipeline.

### Download

The original dataset can be downloaded from Kaggle:

[The Movies Dataset — Kaggle](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset)

After downloading and extracting the dataset, place the required files in the project's `data/raw/` directory.

The preprocessing notebook in `notebooks/preprocess_data.ipynb` can then be used to process the raw data and generate the cleaned dataset used by the project.

Due to the size of the dataset, the raw and processed datasets are **not included in this repository**.

## Data Preprocessing

The preprocessing pipeline includes:

- Removing duplicate and missing records
- Selecting informative movie features
- Parsing metadata such as genres, keywords, cast, and directors
- Extracting the first three cast members
- Extracting the director from crew information
- Combining relevant movie attributes into a unified `metatags` feature
- Extracting release decade and other metadata features

The resulting movie representation combines information from:

```text
Genres
Overview
Tagline
Release Decade
Keywords
Cast
Director
```

## Recommendation Methods

### 1. Popularity-Based Baselines

Two baseline approaches were implemented:

* Average rating
* IMDb-style weighted rating

These baselines provide reference points for evaluating more sophisticated recommendation approaches.

---

### 2. Content-Based Filtering

Content-based recommendations are generated using movie metadata.

The pipeline includes:

1. Creating a combined movie `metatags` representation
2. Converting the text representation into a TF-IDF matrix
3. Limiting the representation to 5,000 features
4. Applying Truncated SVD for dimensionality reduction
5. Computing cosine similarity between movies
6. Returning the most similar movies

Personalized content-based recommendations are also generated by constructing a user profile from the movies the user has rated.

The user profile is weighted according to the difference between each rating and the user's average rating.

---

### 3. Item-Item Collaborative Filtering

An item-item collaborative filtering approach was implemented using:

* User-item rating matrix
* Cosine similarity
* Item-item nearest neighbors

For a given user, recommendation scores are calculated based on the similarity between movies the user has already rated and candidate movies.

---

### 4. Matrix Factorization

Matrix factorization was implemented using **SVD from the Surprise library**.

The model learns latent representations from user-item ratings and predicts ratings for candidate movies.

---

### 5. Hybrid Recommendation

The final recommendation approach combines:

* Matrix Factorization
* Content-Based Filtering

The scores from the two models are normalized and combined using weighted scoring:

```text
Hybrid Score =
    α × MF Score +
    β × Content Similarity
```

The default configuration uses:

```text
MF: 0.7
Content-Based: 0.3
```

Movies already rated by the user are excluded from the final recommendation list.

The system can also provide explanations for content-based recommendations based on shared movie attributes, such as:

* Genres

This helps make recommendations more interpretable instead of returning only a list of movie titles.

## Evaluation

The recommendation models were evaluated using a **Leave-One-Out (LOO)** evaluation strategy.

For each user, the most recent timestamped rating was held out as the test interaction, and the system attempted to recommend that movie among the top-K results.

The following metrics were used:

### Ranking Metrics

* Precision@K
* Recall@K
* Hit Rate@K

### Beyond-Accuracy Metrics

* Catalog Coverage
* Novelty
* Intra-List Diversity (ILD)

The project also reports **95% confidence intervals** for the main ranking metrics.

### Hybrid Model Results

At **K = 20**, the hybrid model achieved approximately:

| Metric       |  Score |          95% CI |
| ------------ | -----: | --------------: |
| Precision@20 | 0.0018 | 0.0011 – 0.0025 |
| Recall@20    | 0.0358 | 0.0224 – 0.0507 |
| Hit Rate@20  | 0.0358 | 0.0224 – 0.0507 |

For the hybrid recommendations:

* **Catalog Coverage:** 0.012
* **Novelty:** 10.78
* **Intra-List Diversity:** 0.96

**Interpretation:** The hybrid model achieved a Recall@20 of 3.58% and a Hit Rate@20 of 3.58%. While the absolute values are relatively low, the evaluation is challenging due to the highly sparse user–item interaction matrix and the large movie catalog. The hybrid approach nevertheless improved over the individual recommendation components, suggesting that combining collaborative and content-based signals can provide complementary information.

## Application

An interactive recommendation application was developed using **Gradio**.

The application provides two main modes:

### By Movie Title

Users can enter a movie title and receive similar movie recommendations based on content similarity.

### By User ID

Users can enter a user ID to receive personalized recommendations using the hybrid recommendation approach.

The application also supports displaying movie poster images when valid poster URLs are available.

## Installation

Clone the repository and install the required dependencies:

```bash
git clone https://github.com/hastijavadzade/movie-recommender-system.git
cd movie-recommender-system
pip install -r requirements.txt
```

### Dataset Setup

1. Download **The Movies Dataset** from [Kaggle](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset).
2. Extract the downloaded files.
3. Place the required raw files inside:

```text
data/raw/
```

4. Run the preprocessing notebook:

```text
notebooks/preprocess_data.ipynb
```

The preprocessing step generates the cleaned movie dataset required by the application.
