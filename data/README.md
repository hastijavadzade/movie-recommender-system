# Data

The raw and processed datasets are not included in this repository due to their size.

Download **The Movies Dataset** from Kaggle and place the required raw files in this directory.

[The Movies Dataset — Kaggle](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset)

After downloading the dataset, place the required files in the project's `data/raw/` directory.

The preprocessing notebook can be found at:

`notebooks/preprocess_data.ipynb`
